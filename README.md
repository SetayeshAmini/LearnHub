# 🎓 LearnHub Academy

**LearnHub Academy** is a modern and responsive educational platform designed for students and aspiring software developers. It provides an interactive environment for exploring programming courses and learning resources.

## 🌐 Live Demo

🔗 **[LearnHub Academy — Live Demo](https://setayeshamini.github.io/LearnHub/)**

## ✨ Features

* 🌙 Dark / Light mode
* 🚀 Interactive Hero section
* 📚 Course catalog
* 🧠 Xpert AI Assistant
* 🔐 Real-time form validation
* 🗺️ Google Maps integration
* 🪟 Glassmorphism UI & animations
* 📱 Fully responsive design

## 🛠️ Technologies

* **HTML5**
* **CSS3**
* **Bootstrap 5.3.3**
* **JavaScript (ES6+)**
* **Bootstrap Icons**
* **Google Maps**

## 📂 Main Sections

* **Navbar** — Navigation & theme switcher
* **Hero** — Introduction, statistics & course search
* **Courses** — Course cards and information
* **Xpert AI** — Interactive assistant
* **Contact** — Contact form, validation & map
* **Footer** — Links, newsletter & social media
